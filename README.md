## How to add testimonials
Open `en/index.html` or `ar/index.html`, find the `<!-- ADD TESTIMONIALS HERE -->` comment
and uncomment + fill the template block.

## Deploy on Vercel
1. Push this whole folder to GitHub (replace or new repo)
2. Vercel → Import → select repo → deploy
3. Done ✓
